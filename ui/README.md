# Sleep Quality UI (Streamlit)

## Prereqs
```bash
py -m pip install -r requirements.txt
```

Ensure the model file exists:

```
reports/sleep_quality_model.joblib
```

(Generated by your training script that saved the combined preprocessor+classifier pipeline.)

## Run the app

```bash
py -m streamlit run ui/app.py
```

## Smoke test

```bash
py ui/smoke_test.py
```
